# Resin by Ash

Storefront + studio admin for Resin by Ash (handmade resin keepsakes, Pakistan).
Next.js 16.4 · React 19.3 · Tailwind CSS 4 · TypeScript. Built by Deep Dev Solutions.

```bash
npm install
npm run dev     # http://localhost:3000  (admin at /admin)
npm run build && npm start
npm run lint
```

- **Frontend handoff (phase 1):** `docs/HANDOFF.md` — what is done, file map, tokens, states, motion, a11y, placeholders.
- **Backend plan (phase 2, for the coding agent):** `docs/phase-2/PLAN.md` + draft `docs/phase-2/schema.prisma`.
- Design source: `extras/` (Claude Design exports). Agent rules for this Next.js version: `AGENTS.md`.
